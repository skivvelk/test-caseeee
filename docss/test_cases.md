TC-01: Счастливый путь — создание, просмотр и удаление задачи

| Элемент | Значение |
|---------|----------|
| ID | TC-01 |
| Название | Полный цикл работы с одной задачей |
| Предусловия | Файл `tasks.json` существует и корректен (можно удалить вручную или запустить `python main.py reset`) |
| Шаги | 1. `python main.py add "Написать отчёт"` <br> 2. `python main.py list` <br> 3. `python main.py remove 1` <br> 4. `python main.py list` |
| Ожидаемый результат | 1. Вывод: `Задача добавлена: 1 | Написать отчёт` <br> 2. Вывод: `1. Написать отчёт` <br> 3. Вывод: `Задача 1 удалена` <br> 4. Вывод: `Список задач пуст` |
| Постусловия | Файл `tasks.json` существует и содержит `[]` |

ТC-02: Ошибочная ситуация — повреждённый JSON

| Элемент | Значение |
|---------|----------|
| ID | TC-02 |
| Название | Восстановление после повреждения данных |
| Предусловия | Существует валидный `tasks.json` с содержимым `[{"id": 1, "title": "test"}]`. Скопируйте его как `tasks.json.backup` |
| Шаги | 1. Записать в `tasks.json` строку `{invalid json` (без закрывающих скобок) <br> 2. `python main.py list` <br> 3. Проверить содержимое `tasks.json` и наличие резервного файла |
| Ожидаемый результат | 2. Вывод: `Ошибка чтения данных: файл повреждён. Восстановление из резервной копии…` и затем нормальный список задач. <br> 3. `tasks.json` восстановлен до содержимого `[{"id": 1, "title": "test"}]`, создан файл `tasks.json.corrupted_<timestamp>` |
| Постусловия | Удалить резервные файлы, оставив чистый `tasks.json` |
